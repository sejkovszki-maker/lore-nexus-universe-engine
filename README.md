# Lore Nexus – Universe Engine

A Diablo-univerzum magyar nyelvű, forrásközpontú tudásbázisa és az általánosítható Universe Engine referencia-alkalmazása.

## Helyi indítás

```bash
npm ci
npm run dev
```

## Ellenőrzés és production build

```bash
npm run quality
npm run build
```

A nyers könyvek, az immutable forrástár, a dokumentumobjektumok, mentések, auditnaplók és generált migrációs csomagok szándékosan nem részei a nyilvános GitHub-tárolónak.
